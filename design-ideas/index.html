Three directions for Transmute Coffee

Same real content in each: 24 projects, versions and star counts pulled from GitHub on 1 Oct 2026. Open each one full-size and try it on your phone too. All three are built with the standalone Tailwind CLI (v4.3.3), no Node, no JavaScript framework.

Concept A

Observatory

Dark and atmospheric. A moonlit hero (pure CSS/SVG, zero image weight) that picks up the moon already on your blog, gold accents and a serif display face.

Best at
Personality and memorability. Feels like a place, not a list.
Trade-off
Hero takes a full screen before any projects. Cards get long as the list grows.

Concept B

Catalogue

Warm paper, editorial type, one row per project. A filter bar (the only JavaScript, and it degrades to "show everything") keeps 24 projects, or 60, easy to scan.

Best at
Scannability and scale. Adding a project is one more row. Lightest CSS (17 KB).
Trade-off
Calmest and least flashy. No imagery, so the personality is all typography.

Concept C

Bento

A modern tile grid. Colour codes the families (purple for Costs to Expect, teal for games, blue for libraries) and tile size shows what matters most.

Best at
Hierarchy at a glance, and giving big projects room to breathe (Prune's editor vignette, Quill's 235k installs).
Trade-off
Every tile is a design decision. Smaller projects collapse into list tiles.
